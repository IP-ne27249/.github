<h2>配好只是开始，日常维护才决定体验</h2>
<p>安卓上把代理配上，十分钟的事。真正麻烦的是后面：应用被杀后台、切换网络后失效、某些应用不认代理、以及息屏后断连。这些问题不解决，用起来会一直别扭。</p>
<p>这篇讲的是配好之后的日常维护，按使用场景给设置要点。</p>

<h2>场景一：办公室固定使用</h2>
<p>固定在一个无线网络下，最省心。设置一次，之后基本不用管。要点是把代理软件加入电池优化白名单，避免被系统清理。</p>
<p>另外建议关闭系统的「智能省电」对该应用的限制。很多「昨天还好今天不行」都是省电策略造成的。</p>

<h2>场景二：家里和办公室两头跑</h2>
<p>换网络后系统代理会失效，因为设置是按网络保存的。解决办法是用全局客户端，它对网络类型不敏感。</p>
<p>如果坚持用系统设置，就要养成习惯：到新网络第一件事是重设代理并验证出口。这个习惯能避免很多「以为在用其实没走」的情况。</p>

<h2>场景三：外出用流量</h2>
<p>系统代理对蜂窝网络无效，这是硬限制。要在这时候也用住宅 IP，只能用客户端全局模式。</p>
<p>但更建议的做法是：出门时不做重要操作。地址从固定变成移动，本身就是环境变化，风险不值得冒。</p>

<h2>场景四：多账号切换</h2>
<p>安卓可以用应用分身或工作资料，把第二个账号装在独立环境，单独设代理。两个环境的数据互不可见。</p>
<p>注意分身环境的代理设置要单独配，不是复制过去的。这一点经常被漏，导致两个账号其实走同一条出口。</p>

<h2>息屏断连怎么修</h2>
<p>三个动作：把代理应用加入电池优化白名单；在最近任务里锁定它，防止被一键清理；关闭系统的「自动管理后台应用」对该应用的限制。</p>
<p>三步做完，绝大多数息屏断连都能解决。如果还不行，说明是软件本身的问题，换个客户端。</p>

<h2>验证的习惯</h2>
<p>每次开始操作前，花十秒在浏览器里查一次出口地址。这个动作看起来多余，但它是唯一能确认「当前真的走了代理」的方法。</p>
<p>尤其是切换过网络、重启过手机、或者装过新应用之后，更要验证一次。</p>

<h2>不要把手机当成主力</h2>
<p>手机端适合查看、适合应急、适合拍照上传，不适合长时间后台操作。屏幕小、操作慢、容易被系统干扰，效率远低于电脑。</p>
<p>更重要的是，手机上报的设备信息更多，环境更复杂，异常概率也更高。核心操作放电脑，手机做辅助，是更合理的分工。</p>

<h2>换手机时的注意点</h2>
<p>新机要重新配置，且要注意两点：一是机型和系统版本尽量与旧机接近，差异过大是异常信号；二是首次登录别在高强度操作下进行，先做几天只读操作。</p>
<p>频繁换设备本身就会被关注。除非必要，别为了尝鲜频繁换机。</p>

<h2>常见问题</h2>
<h3>需要 root 吗</h3>
<p>不需要。系统代理和全局客户端都不要求 root。需要 root 的方案风险高，不建议在承载账号的手机上用。</p>
<h3>能不能用平板代替手机</h3>
<p>可以。平板的系统限制通常比手机少，后台保活更容易，适合做固定操作。</p>
<h3>为什么某些应用一直连不上</h3>
<p>该应用不读系统代理。解决方法是全局模式或分应用代理，硬在系统设置里调没用。</p>
<h3>代理开着会影响其他应用吗</h3>
<p>全局模式下会，可能拖慢国内应用。用分应用模式可以避免。</p>
